# Рейс в Т-хаб

[Открыть игру](https://denysque.github.io/t-hub-flight-game/)

Опубликованная браузерная версия: до 200 участников, отдельный пульт модератора и экран гостей, радар ожидания, фуражки пилотов, объявления победителей и турнир 200 → 100 → 50 → 25 → 10 → 1.

## Запуск

1. Откройте игру на ноутбуке и нажмите «Открыть регистрацию».
2. Нажмите «Открыть экран гостей» и перенесите это окно на проектор.
3. Участники сканируют QR-код, вводят имя и при желании загружают фото.
4. Держите пульт модератора видимым и ноутбук включённым до конца игры.

Игра размещается на GitHub Pages. Состоянием управляет браузер ведущего; устройства обмениваются зашифрованными сообщениями через MQTT. В публичном репозитории находятся только готовые файлы сайта. Данные участников и ключи комнат сюда не записываются.

Проверьте связь на Wi-Fi и мобильной сети площадки перед мероприятием: публичный канал связи не предоставляет гарантии непрерывной работы. 200 участников — предусмотренная вместимость; реальные задержки зависят от сети и ноутбука.
